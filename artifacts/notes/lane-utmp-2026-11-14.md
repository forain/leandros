# lane/utmp 2026-11-14 - utmpx/wtmp/lastlog

Consumers: Alpine busybox-static (1.37) has applets `who` and `last` (no `w`, no `users`). It links
skarnet utmps: `who` talks to a daemon on /run/utmps/.utmpd-socket, `last` reads /var/log/wtmp directly.
Alpine's musl utmpx is a stub, so nothing else reads utmp.

Implemented: lib/utmpx/utmpx.rs (core-only, raw syscalls, 400-byte utmps struct), userland/utmpd (utmps
protocol e/i/l/E/r, sequential, per-connection file position, putline root-only), writers in init (BOOT_TIME,
RUN_LVL, DEAD_PROCESS on reap), login (console/VT, line from /proc/self/fd/0), sshd (pty sessions, ut_host =
peer ip), pam-leandros (greetd service). Test: sshsmoke.py utmp_* steps. Not written: su/sudo (by design).
Open: no `w` consumer; lastlog has no reader; concurrent writers rely on flock only.
