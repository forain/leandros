# lane/i915flip — 2026-10-24 (openbugs L8.9)

## (a) per-flip clflush — FIXED (policy); cost was already 0 for cosmic-comp
- Baseline on the old good kernel at the idle greeter: 1853 flips, `flip_clflush_us 0`.
  cosmic-comp (smithay) PRIME-exports its GBM BOs, so the "8 MB per flip" only hit non-PRIME scanout.
- New `i915.kms_clflush=2` default (drivers/src/i915/uapi.rs `kms_bo_needs_clflush`): flush only when
  the BO is bound cached (`kms_uncached=0`), has a CPU mapping (`cpu_wb`, sticky, because every i915 mmap is
  write-back), or had a PWRITE / SET_DOMAIN(CPU write) since the last flip (`cpu_dirty`, consumed before
  the flush). GPU writes need no flush: Mesa allocates every GBM/KMS buffer SHARED (gbm_dri always adds
  __DRI_IMAGE_USE_SHARE -> iris_bo_mark_exported -> PTE MOCS -> uncached PTE; heap SYSTEM_MEMORY_UNCACHED).
  The old PRIME rule is kept as `i915.kms_clflush=3`; `1` = always, `0` = never.
- Not done: honoring MMAP_OFFSET_WC/UC (all CPU maps are WB, hence the sticky rule).

## (b) watermarks — FIXED (ported), SAGV check added
- kms.rs `skl_wm_latency` (pcode GEN9_PCODE_READ_MEM_LATENCY, zero-level cutoff, WaWmMemoryReadLatency)
  + `skl_plane_wm` (method1/method2, gen9 min rule, WA #1126, lines<=31, min_ddb = blocks*1.1 must fit
  the plane's DDB) for a linear XRGB8888 unscaled plane with no IPC (WM_TRANS off, as in Linux). The scaled-GOP
  fallback is kept (`i915.native_wm=2` forces it). `skl_sagv_check` disables SAGV via pcode 0x21 if the
  top enabled level is below 30 us (Linux skl_can_enable_sagv); `i915.sagv=1` skips this.
- Laptop: latencies [2,19,28,32,63,77,83,99] us, 138699 kHz, htotal 2080, DDB 446 -> all 8 levels
  enabled (L0 4 blocks/1 line ... L7 110 blocks/7 lines). The old scaling enabled level 0 only. SAGV kept (99 >= 30).
- Approximated: the plane DDB is the GOP's allocation (not Linux's full-pipe allocation); one plane + cursor.

## Underrun counter
- The pipe A FIFO-underrun bit stays unmasked in IMR (IER off) and is counted by the display IRQ and a poll.
  /proc/i915 shows `fifo_underruns` and `flips_clflushed`. It counts latched frames, not events. Not proven to fire
  (an underrun cannot be forced on HW).
