# lane/nslo (podnet P2) - 2026-11-10

Each non-initial netns now gets a real loopback stack. First `lo` up (netlink RTM_NEWLINK or SIOCSIFFLAGS) allocates a
dynamic stack (127.0.0.1/8 on a LoopDev, same as sid 0) via a new `sched::ns::set_lo_hook` -> `vif::set_lo`; later
up/down only flips the admin bit. The daemon polls every dynamic loopback stack. Reaping: death hook as before;
`set_lo` also reaps a stale id and, when all slots are used, runs a reap pass itself.

Void gates removed: bind (lo up needed for 127.0.0.1), connect/send/ICMP/UDP/listen now go through route lookups.
`route_select`, `ns_sids`, `stacks_for`, `stack_holding`, `udp_stack` no longer fall through to netns 0's lo/NICs.
Non-initial listeners/UDP servers are not put in the global adopt registries (a late NIC would otherwise adopt them).
lo down: connect/sendto -> ENETUNREACH; wildcard bind/listen with lo never up stay table-only entries.
Bug found on the way: `iface::can_route` indexed IFRT with `sid-1` for a dynamic sid (hang); dynamic sids are lo-like now.

Tests (nstest): netns_lo_echo (down fails, up TCP/UDP/ping, down again), netns_lo_two_ns_same_port,
netns_lo_host_unreachable, netns_lo_slots_reclaimed (100 netns lo up in a row).

NOT DONE: IPv6 / ::1 (the stack has no IPv6 at all, also in netns 0); sockets bound while lo was down are not
materialized when lo comes up later; D7 cap check unchanged (nlns/netnsfix).
