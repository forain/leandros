# lane/s3aml 2026-10-28: AML sleep methods (no sleep state ever entered)

DELIVERED (interpreter + dry-run), with one hardware finding.

## What
- `acpi_power::{sleep_prepare, sleep_wake, tts, sx_typ, pause_poll, s3_dryrun}`: `_TTS`/`_PTS`/`_SI._SST`/`_WAK`/`\_Sx_`; per-method result and per-space OpRegion read/write/dropped counters in `[S3] aml:` lines (klog).
- aml.rs: every region space now reaches the host; KHost serves SystemCMOS reads (0x70/71, 0x72/73), counts dropped SMBus/GPIO/GSBus/PCC accesses, CMOS writes only with `pm.aml_cmos_write=1`.
- `Field(Lock)` takes the FACS global lock (cmpxchg FACS+16, pending -> GBL_RLS in PM1a_CNT on release, reentrant).
- Sleep() honours 2000 ms inside the sleep window; kacpid `poll()` stops while paused.
- Knobs: `pm.s3_dryrun=1` (8 s after boot: `\_S0_/\_S3_/\_S5_`, then `_TTS(3)`, `_PTS(3)`, `_SST(3)`, never SLP_EN), `=2` also `_WAK(3)`; `pm.amltrace=1` logs the first 200 writes per group.
- Host tests: `cargo test --manifest-path drivers/acpi-aml-tests/Cargo.toml --target aarch64-apple-darwin` (5/5).

## Evidence
- QEMU x86_64: `\_S3_` 0x1/0x1, no `_PTS`/`_WAK` in the QEMU DSDT (reported absent, no errors). aarch64 boots.
- Laptop (EliteBook 840 G5, trial 151aa042909f, dry-run=1+amltrace): `\_S0_` 0/0, `\_S3_` 5/0, `\_S5_` 7/0. `_PTS(3)` ok: Mem w8 to 0xb7b5d00b.. (NVS), IO 0x24e/0x24f/0x80, no EC writes, no dropped accesses, global-lock fails 0. `_TTS`, `_SST` absent.
- `_WAK(3)` (run back-to-back in that first version): writes NVS, EC 0x87/0x88/0x82/0xe3/0xf7, Mem 0xfed159a0, then **IO 0xb2 w16 = 0xea91 (SMI_CMD)** as the last klog line, after which the laptop rebooted onto good (uptime 18 s when checked). So `_WAK(3)` without a real S3 entry hits an SMM call that resets the machine. Hence `_WAK` is now opt-in (`pm.s3_dryrun=2`); the real suspend must run it only after an actual wake. Not retried.
- Afterwards: laptop on good b01ea05b, ssh fine, trial discarded/not armed. Display/battery/Wi-Fi not checked in detail (the sysfs path used did not exist over remote run); not promoted.
- The reboot was not a lapreboot-style power-off: it came back by itself.
