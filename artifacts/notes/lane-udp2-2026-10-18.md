# lane/udp2 — 2026-10-18

Branch `lane/udp2` off local main `0a63f5cb`. Not merged, not pushed.
Everything is in `servers/net` (linked into the kernel; a laptop deploy needs
a kernel reboot) and its vendored smoltcp; no kernel/syscall change.

Closes the "UDP gaps (lane-udp)" list of TODO.md and the netwatch.loss test.

## What changed

**smoltcp (vendored, every change marked `LEANDROS`, see
`servers/net/vendor/smoltcp/LEANDROS-PATCH.md`)** — features `proto-igmp`,
`proto-ipv4-fragmentation`, `reassembly-buffer-count-16`,
`iface-max-multicast-group-count-32`.

1. UDP demultiplexing like Linux: broadcast/multicast to every socket on the
   port; unicast to the best match (bound address, connected peer), newest
   bind on a tie, SO_REUSEPORT group by flow hash. Connected sockets filter
   by peer at demux time (`set_peer`), so a re-connect keeps queued datagrams.
2. `UdpMetadata` carries destination, TOS, TTL (rx) and source/TTL per
   datagram (tx); `PacketMeta::tos` = IP_TOS (also on fragments).
3. ICMP dest-unreachable / time-exceeded reach sockets: connected UDP gets a
   fatal one as pending error; TCP SYN-SENT whose SYN (ports + seq) is
   quoted closes with the errno (`icmp_errno`). `Icmpv4Repr::parse` used to
   drop every error quoting a truncated packet (total_len > quote).
4. Fragmentation: payloads multiple of 8 (upstream used the whole MTU), Vec
   fragmenter buffer, no overwrite of an in-flight fragmented packet, all
   fragments in one poll; reassembly refuses > 65535, drops whole datagram
   on error, frees big buffers.
5. `send_pending`, `unbind_port`, `ipv4_multicast_groups`.
6. 9 new host tests (`tests/leandros.rs`); 591/591 with the crates.io Cargo.toml.

**net server**

- `mcast.rs`: IP_ADD/DROP_MEMBERSHIP (ip_mreq/ip_mreqn), per-description
  membership, interface join refcount (IGMPv2 report/leave), release on last
  close, `/proc/net/igmp` (Linux format).
- `ip_setsockopt`/`ip_getsockopt`: IP_TOS, IP_TTL, IP_PKTINFO, IP_RECVTTL,
  IP_RECVTOS, IP_RECVERR (accepted), IP_MULTICAST_TTL/LOOP/IF/ALL; SOL_UDP
  UDP_GRO.
- Local copy of own broadcast / looped multicast: frame built and queued to
  the interface's receive side (`INJECT`, `loop_frame`).
- SO_BROADCAST enforced on send and connect (`iface::is_broadcast`).
- recvmsg cmsgs (UDP_GRO, IP_PKTINFO, IP_TTL, IP_TOS) with MSG_CTRUNC;
  UDP_GRO coalesces same-source equal-size runs (`udp_next_locked`).
- Pending ICMP error: recv/recvmsg/send answer it once, POLLERR, SO_ERROR
  reads and clears; error bit in the readiness byte (EPOLLET edge).
- `inet_disconnect`: UDP AF_UNSPEC gives up an automatic port (bind_lock
  tracks Linux's SOCK_BINDADDR/BINDPORT_LOCK), rebinding at the next
  send/connect/bind; TCP AF_UNSPEC aborts (RST), stops a listener,
  unconnected again.
- NIC smoltcp MTU 1500 -> 1514 (it included the Ethernet header: IP MTU was
  1486, TCP MSS 1446 -> now 1460).
- Found by the peer test, fixed: a wildcard bind with port 0 (quinn-udp's
  bind) lived on one stack — datagrams arriving through another interface
  got a port unreachable and sends left by the wrong route; now every
  wildcard bind is a `udpany` server. Mirrors' buffers were 32 KiB tx, so a
  64 KiB datagram blocked its sender forever (EAGAIN); now 128 KiB, and a
  datagram larger than the send buffer is EMSGSIZE. A UDP socket closed
  right after sendto lost its datagram (removed before the daemon sent it);
  it is now kept until its queue is out (`reap_orphans`).

## Open

- Real NICs: drivers program no multicast filter; mDNS verified only on
  virtio-net (QEMU receives all multicast). Check iwlwifi on the laptop.
- No IP_RECVERR error queue, no IP_PKTINFO on sendmsg, no PMTU discovery, no
  IGMPv3 / source-specific joins.
- SO_RCVTIMEO/SO_SNDTIMEO are accepted and ignored (both test files use
  poll + MSG_DONTWAIT instead).
- Ephemeral ports are lowest-free: a just-freed port comes right back (two
  test cases first failed on that; Linux randomizes).
