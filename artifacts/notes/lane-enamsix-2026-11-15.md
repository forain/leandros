# lane/enamsix (EC2 design lane L8) - 2026-11-15

DELIVERED: interrupt-driven ENA (mock-verified) and NVMe (QEMU-verified) on x86_64 via MSI-X, polled fallback everywhere else.
- ENA core (`ena_hw.rs`): `set_msix_allowed`, CREATE_CQ with `interrupt_mode_enabled` (cq_caps_1 bit 5) and MSI-X entry 1 for both CQs of the pair, CQ interrupt-unmask register read from the CREATE_CQ response (offset 20), unmask (bit 30) after bring-up and in `irq_rearm`, admin interrupt unmasked (INTR_MASK = 0) so AENQ fires entry 0. A refused interrupt-mode CQ or a missing unmask register redoes the bring-up polled (like the LLQ fallback). A watchdog reset rebuilds the CQs in interrupt mode.
- ENA glue (`ena.rs`): `MsixTable::enable` + entries 0/1, ISRs only count and `netdev::kick_from_irq`; `rx_rearm` unmasks, `rx_irq_driven` true; `ena.msix=0`; aarch64 stays polled automatically (`MsixTable::enable` returns Unsupported until the ITS lane). /proc/net/nic: irq_mode, irqs_mgmt, irqs_io.
- Mock (`drivers/ena-tests`): CQ interrupt model (auto-mask after firing, unmask re-fires queued work), AENQ vector 0, 46 tests (10 new: vector assignment, unmask doorbell, one-interrupt-until-rearm, rearm-with-pending, 10k loopback without a lost wakeup, AENQ irq, two fallbacks, reset recovery).
- NVMe (`nvme.rs`): opt-in `nvme.msix=1` (x86_64): one vector for admin + I/O CQ (IV 0, IEN), ISR counts and notifies a `LinkMon`; sleeping waiters park on it with a 2 ms safety slice (a lost interrupt costs 2 ms, never a hang); kenv shims for built-in and module (nvme.ko) builds. Test `.claude/skills/run-leandros/nvmemsixtest.py` (QEMU x86_64, 2 boots msix=1 / msix=0): PASS, counter rose, polled fallback intact.
- MEASURED (Mac QEMU, not KVM; informational): 8 MiB read CPU ticks msix=1 124 vs polled 75; with 1500 IOPS throttle 115 vs 99. No CPU win on QEMU (interrupt delivery costs more than the 50 us - 1 ms polled slices), so NVMe MSI-X is NOT default; idle-vs-load on KVM and real EBS latency unmeasured.

UNPROVEN (needs real EC2): CREATE_CQ msix_vector field position (bytes 8..11), CQ unmask register offset (response byte 20) and bit 30, per-pair vector numbering (entry 1) are from memory of the public ENA headers, encoded identically in driver and mock.
