## C — blkfaulttest (SIGBUS against a dead virtio-blk): TEST FIXED, SCENARIO STILL RED
The committed driver could not run: `setsid` does not exist in the guest, and a
trailing `&` breaks the driver's `; __r=$?` marker. Now launches `sh -c '…' & true`.
Once it runs it FAILS, correctly: the touch of a mapped page of a hung disk
reads zeros (`READ_OK sum=0`, frc=0, no SIGBUS). Cause found: `fetch_read`
(servers/f2fs/src/lib.rs, "if !ok { buf.fill(0); }") installs a failed device
read as valid zero blocks in the block cache, and the nostall retry path then
serves them. A real fix needs a per-mount I/O-error flag so the request fails
with EIO (and FillErr::Io -> Fault::Bus, which install_file_fault already maps).
Not in regress. Run: `python3 .claude/skills/run-leandros/blkfaulttest.py aarch64`.
