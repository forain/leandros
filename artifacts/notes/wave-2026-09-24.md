## Process lessons
- **Shared non-git sibling checkouts collide across worktrees.** `../doomgeneric` resolves to the same physical directory for every worktree on a machine; one lane's `make clean` could delete another's in-flight build. Fixed at the Makefile/build-script level (buildobj), but the general hazard — any shared sibling directory outside this repo's worktrees — applies to `cosmic-epoch` too (sessmisc/icons both had to add fallback resolution and loud failures rather than silently shipping an empty/stale subset).
- **A machine-wide build lock is mandatory** whenever more than one lane can run `build-all.sh` on the same host: the protocol note's `mkdir`-based lock (with a trap to always release it) prevented a repeat of an earlier wave's build collision, but at least one lane still had its build **step on another lane's build in progress before the lock convention was universally followed**, wasting a cycle — always wait for the lock rather than checking whether it "looks free."
- **Idle agents parked in a long build/QEMU boot need an explicit wake-up.** Several lanes' background builds or multi-minute QEMU boots ran well past a plain foreground wait; the orchestrator had to poll/Monitor them rather than assume a silent agent had stalled.
- **SDKROOT must be pinned on the Mac for every build.** The host's default `xcrun`-resolved SDK (`MacOSX27.0.sdk`) is broken for host-side linking ("tapi error: malformed file" / unknown architecture `arm64e.x1`); every lane that built on the Mac needed `export SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk` first. This is environmental, not a kernel bug, and independent lanes rediscovered it separately (buildobj, execleak, vfsmisc, polltimer) before it was written down once.
- **User rule, enforced mid-wave: GPU rendering only, no COSMIC source patches.** greeterlag's blur-skip patch to cosmic-comp (`e624610`) fixed a real 4 s/frame softpipe stall but was **reverted** (`d16c563`) for violating the "don't patch COSMIC source" boundary — the sanctioned fix is GPU rendering (gpudefault/virglpanel), which happened to remove the same trigger by a different route (real GPU compositing, not a slower blur skip).
