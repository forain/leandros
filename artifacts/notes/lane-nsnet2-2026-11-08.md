# lane/nsnet2 2026-11-08 (follow-up to nsnetipc)

FIXED (aarch64). servers/net/src/lib.rs:
1. SockEntry.netns captured at socket()/socketpair() (accepted unix sockets inherit the listener's);
   sock_netns(pid, slot) is used for AF_INET bind/connect/sendto gates and abstract AF_UNIX bind/connect.
   SCM_RIGHTS copies and fork carry the field, so a passed socket keeps the creator's netns and a
   socket created before unshare(NEWNET) keeps the old one.
2. Per-netns port space: bind_conflict only compares sockets of the same netns; TIME_WAIT reservations
   apply to the initial netns only; listen() in a non-initial netns registers no stack listener
   (unreachable from the host, host connect -> ECONNREFUSED).
Tests (nstest): sock_netns_inherited, sock_netns_scm, sock_before_unshare, netns_portspace - all 4 FAIL
on unfixed kernel (ENETUNREACH / EADDRINUSE), PASS after. nstest + nettest PASS.
Open: UDP wildcard bind in a child netns still materializes a real stack socket (host-reachable);
ephemeral port allocation still avoids ports across all netns (harmless); no /proc/<pid>/ns/{net,ipc}.
