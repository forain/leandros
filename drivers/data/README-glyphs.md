# Wide-glyph table sources

`wide-glyphs.bin` is a derived bitmap table (16x16 monochrome glyphs for the
double-width code points the VT console draws), compiled into the kernel by
`drivers/src/glyphs.rs`. It is generated by `scripts/gen-wide-glyphs.py`, which
verifies the sha256 of both inputs before use. Regeneration command: see the top
of that script. The inputs are not stored in the repository.

  fonts (Unifont bitmaps verbatim; Noto Emoji outlines rasterised and
  thresholded), used for the kernel console. Unifont glyphs take precedence;
  Noto Emoji only fills supplementary-plane emoji Unifont lacks.

## Narrow-glyph table

`narrow-glyphs.bin` holds the 8x16 Unifont glyphs (same pinned
`unifont_all-18.0.01.hex`, same license) for single-width non-ASCII code points
(U+00A0..U+2BFF, U+FB00..FB06, U+FFFD; 5133 glyphs, 85 KB). Generated by
`scripts/gen-narrow-glyphs.py`; used by `glyphs::narrow_glyph` after the
procedural box/block/symbol glyphs.
